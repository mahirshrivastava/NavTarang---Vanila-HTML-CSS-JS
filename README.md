# Navtarang
Static website built with HTML and CSS.

Repository: https://github.com/mahirshrivastava/navtarang.github.io

# Summary

Simple static website comprised of HTML pages, CSS styles, fonts and images.
Languages: HTML (87.5%), CSS (12.5%)
Contents

- index.html — main entry page
- home.html — home page
- product.html — product or catalogue page
- register.html — registration page
- Login.html — login page
- CSS/ — stylesheet files
- Font/ — custom fonts used by the site
- IMG/ — images and assets
- LICENSE — repository license file
- Features

- Responsive/static HTML pages styled with plain CSS
- Organized asset folders for fonts and images
- Ready to be served locally or deployed with GitHub Pages

## How to view locally
- Clone the repository: git clone https://github.com/mahirshrivastava/navtarang.github.io.git
- Open a page directly:
- Double-click index.html (or any HTML file) in the repo root to open it in a browser OR
- Serve with a simple HTTP server (recommended for correct font/asset loading):
- Python 3: python -m http.server 8000
- Then open http://localhost:8000 in your browser
- Deploy to GitHub Pages

This repository is already structured as a static site and can be published via GitHub Pages.
In repository Settings → Pages, select the main branch (root) as the source and save.

# Development notes

All markup is plain HTML and styling is in the CSS folder. No build tools are required.
To modify styles, edit files inside the CSS/ folder and refresh the pages in the browser.
Fonts are stored in Font/ and referenced from CSS; ensure paths remain correct if reorganizing.
